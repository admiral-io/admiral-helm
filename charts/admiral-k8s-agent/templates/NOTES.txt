{{- $fullName := include "admiral-k8s-agent.fullname" . -}}

==========================================================================
  Admiral Kubernetes Agent
==========================================================================

  Agent:       {{ $fullName }}
  Namespace:   {{ .Release.Namespace }}
  Admiral:     {{ .Values.admiral.server }}
  Signs in as: {{ .Values.admiral.serviceAccountId }}
  {{- if .Values.admiral.insecure }}
  TLS:         DISABLED (admiral.insecure)
  {{- end }}
  {{- if .Values.allowedNamespaces }}
  Deploys to:  {{ join ", " .Values.allowedNamespaces }}
  {{- else if .Values.rbac.namespaces }}
  Deploys to:  {{ join ", " .Values.rbac.namespaces }}
  {{- else }}
  Deploys to:  every namespace
  {{- end }}

  Wait for the agent to start:
    kubectl rollout status --namespace {{ .Release.Namespace }} deploy/{{ $fullName }}

  Read its logs:
    kubectl logs --namespace {{ .Release.Namespace }} deploy/{{ $fullName }} -f

  The agent logs "Starting admiral-k8s-agent" at startup. Each status report
  that does not reach Admiral logs "Heartbeat failed" with the reason. The pod
  is NotReady until a report reaches Admiral, and again after three failures
  in a row, which shows in:
    kubectl get pods --namespace {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
{{- if .Values.enrollment.existingSecret }}

--------------------------------------------------------------------------
  Enrollment
--------------------------------------------------------------------------

  The agent enrolls with the key in Secret "{{ .Values.enrollment.existingSecret }}".
  The logs show "Enrollment did not complete" if Admiral refused it. The key
  is single-use; once the agent is enrolled you can delete the Secret.
{{- end }}
{{- if not .Values.rbac.create }}

--------------------------------------------------------------------------
  RBAC
--------------------------------------------------------------------------

  rbac.create=false: the chart granted the service account
  "{{ include "admiral-k8s-agent.serviceAccountName" . }}" nothing. The agent needs at least
  get on the kube-system namespace to start, get, patch and create on every
  kind it plans, and delete on every kind it applies.
{{- end }}
